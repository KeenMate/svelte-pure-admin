# Internationalization (i18n)

Svelte Pure Admin includes a lightweight, built-in internationalization system for translating component strings. It uses Svelte 5 runes for reactive language switching.

## Overview

The i18n system provides:
- **Built-in translations** for English (`en`) and Czech (`cs`)
- **Reactive locale switching** - UI updates instantly when language changes
- **Server preloading support** - Embed translations in index.html to avoid request waterfalls
- **Custom translation loading** - Async loading from API/database
- **String overrides** - Customize any component string
- **No external dependencies** - Lightweight, built into the library

## Quick Start

### Basic Usage (Default English)

No configuration needed - components use English by default:

```svelte
<script>
  import { PureAdminProvider } from '@keenmate/svelte-pure-admin';
</script>

<PureAdminProvider>
  <!-- All components use English strings by default -->
  <App />
</PureAdminProvider>
```

### Switch to Czech

```svelte
<script>
  import { PureAdminProvider } from '@keenmate/svelte-pure-admin';
</script>

<PureAdminProvider config={{
  i18n: {
    locale: 'cs'
  }
}}>
  <!-- All components now use Czech strings -->
  <App />
</PureAdminProvider>
```

### Dynamic Language Switching

```svelte
<script>
  import { i18nStore } from '@keenmate/svelte-pure-admin';

  function switchToCzech() {
    i18nStore.setLocale('cs');
  }

  function switchToEnglish() {
    i18nStore.setLocale('en');
  }
</script>

<button onclick={switchToCzech}>Čeština</button>
<button onclick={switchToEnglish}>English</button>

<!-- Current locale: {i18nStore.locale} -->
```

## Configuration

### I18nConfig Interface

```typescript
interface I18nConfig {
  /** Current locale code (e.g., 'en', 'cs') */
  locale: string;

  /** Fallback locale when translation is missing (default: 'en') */
  fallbackLocale?: string;

  /** Available languages for language selector */
  languages?: LanguageItem[];

  /** Pre-loaded translations (from server or static) */
  translations?: Record<string, Partial<TranslationKeys>>;

  /** Async loader for fetching translations on language switch */
  loadTranslations?: (locale: string) => Promise<Partial<TranslationKeys>>;
}

interface LanguageItem {
  code: string;    // 'en', 'cs'
  name: string;    // 'English', 'Čeština'
  flag?: string;   // Country code for flag images: 'gb', 'cz'
}
```

### Full Configuration Example

```svelte
<script>
  import { PureAdminProvider } from '@keenmate/svelte-pure-admin';

  // Languages available in your app
  const languages = [
    { code: 'en', name: 'English', flag: 'gb' },
    { code: 'cs', name: 'Čeština', flag: 'cz' },
    { code: 'de', name: 'Deutsch', flag: 'de' }
  ];

  // Pre-loaded translations (e.g., from server)
  const translations = {
    en: {
      dialog: { confirm: 'Yes, proceed', cancel: 'No, go back' }
    },
    cs: {
      dialog: { confirm: 'Ano, pokračovat', cancel: 'Ne, zpět' }
    }
  };

  // Async loader for additional languages
  async function loadTranslations(locale) {
    const response = await fetch(`/api/translations/${locale}`);
    return response.json();
  }
</script>

<PureAdminProvider config={{
  i18n: {
    locale: 'cs',
    fallbackLocale: 'en',
    languages,
    translations,
    loadTranslations
  }
}}>
  <App />
</PureAdminProvider>
```

## Server Preloading (Recommended)

To avoid request waterfalls (page loads → fetch languages → fetch translations), embed initial data in your HTML:

### Server Response (index.html)

```html
<!DOCTYPE html>
<html>
<head>
  <script>
    // Embedded by server based on user's locale preference
    window.__ADMIN_CONTEXT__ = {
      locale: 'cs',
      languages: [
        { code: 'en', name: 'English', flag: 'gb' },
        { code: 'cs', name: 'Čeština', flag: 'cz' }
      ],
      translations: {
        cs: {
          dialog: { confirm: 'Potvrdit', cancel: 'Zrušit' },
          // ... other translations
        }
      }
    };
  </script>
</head>
<body>
  <div id="app"></div>
</body>
</html>
```

### SvelteKit Integration

```svelte
<!-- +layout.svelte -->
<script>
  import { PureAdminProvider } from '@keenmate/svelte-pure-admin';
  import { browser } from '$app/environment';

  // Get context from server-rendered HTML
  const ctx = browser ? window.__ADMIN_CONTEXT__ : { locale: 'en' };
</script>

<PureAdminProvider config={{
  i18n: {
    locale: ctx.locale,
    languages: ctx.languages,
    translations: ctx.translations
  }
}}>
  <slot />
</PureAdminProvider>
```

## Using Translations in Your Code

### useI18n Hook

Access the full i18n store:

```svelte
<script>
  import { useI18n } from '@keenmate/svelte-pure-admin';

  const i18n = useI18n();

  // Get current locale
  $: currentLocale = i18n.locale;

  // Get available languages
  $: languages = i18n.languages;

  // Check loading state
  $: isLoading = i18n.isLoading;

  // Translate a key
  const text = i18n.t('dialog.confirm');

  // Change locale
  function switchLocale(code) {
    i18n.setLocale(code);
  }
</script>

{#if isLoading}
  <span>Loading translations...</span>
{:else}
  <span>{i18n.t('dialog.confirm')}</span>
{/if}
```

### useTranslate Hook

Get just the translation function:

```svelte
<script>
  import { useTranslate } from '@keenmate/svelte-pure-admin';

  const t = useTranslate();
</script>

<button>{t('dialog.confirm')}</button>
<button>{t('dialog.cancel')}</button>
```

### useScopedTranslate Hook

Get a scoped translation function for a specific namespace:

```svelte
<script>
  import { useScopedTranslate } from '@keenmate/svelte-pure-admin';

  // All translations prefixed with 'dialog.'
  const t = useScopedTranslate('dialog');
</script>

<button>{t('confirm')}</button>  <!-- Same as t('dialog.confirm') -->
<button>{t('cancel')}</button>   <!-- Same as t('dialog.cancel') -->
```

### Direct Store Access

Import and use the store directly:

```svelte
<script>
  import { i18nStore } from '@keenmate/svelte-pure-admin';
</script>

<p>Current locale: {i18nStore.locale}</p>
<p>Confirm text: {i18nStore.t('dialog.confirm')}</p>
```

## Adding Custom Translations

### Override Specific Strings

```svelte
<PureAdminProvider config={{
  i18n: {
    locale: 'en',
    translations: {
      en: {
        dialog: {
          confirm: 'Yes, I\'m sure',
          cancel: 'No, take me back'
        }
      }
    }
  }
}}>
```

### Register Translations at Runtime

```svelte
<script>
  import { i18nStore } from '@keenmate/svelte-pure-admin';

  // Add or update translations for a locale
  i18nStore.registerTranslations('en', {
    dialog: {
      confirm: 'Proceed',
      cancel: 'Abort'
    }
  });
</script>
```

### Add a New Language

```svelte
<script>
  import { i18nStore } from '@keenmate/svelte-pure-admin';

  // Register German translations
  i18nStore.registerTranslations('de', {
    dialog: {
      confirm: 'Bestätigen',
      cancel: 'Abbrechen',
      ok: 'OK',
      alert: 'Warnung',
      input: 'Eingabe',
      areYouSure: 'Sind Sie sicher?',
      enterValue: 'Wert eingeben:',
      defaultTitle: 'Dialog',
      invalidInput: 'Ungültige Eingabe'
    },
    popconfirm: {
      confirm: 'Bestätigen',
      cancel: 'Abbrechen'
    },
    shortcuts: {
      title: 'Tastenkürzel',
      noShortcuts: 'Keine Tastenkürzel registriert.',
      generalCategory: 'Allgemein',
      showShortcuts: 'Tastenkürzel anzeigen'
    },
    commandPalette: {
      placeholder: 'Tippen Sie / für Befehle, : für Suche...',
      loading: 'Wird geladen...',
      commands: 'Befehle',
      searchIn: 'Suchen in',
      search: 'Suchen',
      noMatchingCommands: 'Keine passenden Befehle',
      typeToSearch: 'Tippen zum Suchen...',
      noMatchingContexts: 'Keine passenden Suchkontexte',
      noResults: 'Keine Ergebnisse',
      navigate: 'Navigieren',
      select: 'Auswählen',
      complete: 'Vervollständigen',
      close: 'Schließen'
    },
    loadMore: {
      loadMore: 'Mehr laden',
      loading: 'Wird geladen...'
    }
  });

  // Now switch to German
  i18nStore.setLocale('de');
</script>
```

## Language Selector Component Example

```svelte
<script>
  import { i18nStore } from '@keenmate/svelte-pure-admin';

  async function changeLanguage(event) {
    await i18nStore.setLocale(event.target.value);
  }
</script>

<select value={i18nStore.locale} onchange={changeLanguage} disabled={i18nStore.isLoading}>
  {#each i18nStore.languages as lang}
    <option value={lang.code}>
      {lang.flag ? `🇬🇧` : ''} {lang.name}
    </option>
  {/each}
</select>

{#if i18nStore.isLoading}
  <span>Loading...</span>
{/if}
```

## API Reference

### i18nStore

| Property/Method | Type | Description |
|-----------------|------|-------------|
| `locale` | `string` | Current locale code |
| `fallbackLocale` | `string` | Fallback locale code |
| `languages` | `LanguageItem[]` | Available languages |
| `translations` | `TranslationKeys` | Current merged translations |
| `isLoading` | `boolean` | True when loading translations |
| `t(key, params?)` | `(string, object?) => string` | Translate a key |
| `setLocale(locale)` | `(string) => Promise<void>` | Change locale (async if loading needed) |
| `initialize(config)` | `(I18nConfig) => void` | Initialize from config |
| `registerTranslations(locale, translations)` | `(string, Partial<TranslationKeys>) => void` | Add/update translations |
| `hasLocale(locale)` | `(string) => boolean` | Check if locale has translations |

### Hooks

| Hook | Returns | Description |
|------|---------|-------------|
| `useI18n()` | `i18nStore` | Full i18n store access |
| `useTranslate()` | `(key, params?) => string` | Translation function only |
| `useScopedTranslate(scope)` | `(key, params?) => string` | Scoped translation function |

## Best Practices

1. **Pre-load translations** - Embed initial translations in HTML to avoid loading delays
2. **Use fallback locale** - Always set a fallback to ensure strings are never missing
3. **Lazy load additional languages** - Only load translations when user switches language
4. **Cache translations** - The store caches loaded translations automatically
5. **Use scoped translators** - Reduces boilerplate in components that use many strings from one namespace
